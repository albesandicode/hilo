# hilo-web

Frontend de Hilo (Angular 22). Visión general y cómo arrancar todo: [`../README.md`](../README.md).

```bash
npm ci          # instala dependencias exactas del package-lock
npm start       # http://localhost:4200 (las llamadas a /api van al backend por proxy.conf.json)
npm test        # tests con Vitest
npm run build   # build de producción en dist/
```
